# Library Desk

Library Desk is a PHP/MySQL library management application.

## Run the full PHP application locally

Use XAMPP (or another PHP/MySQL server):

1. Place the project in the server's web root.
2. Start Apache and MySQL.
3. Import `database/library_db.sql` into MySQL.
4. Open the project through the local web server (for XAMPP, `http://localhost/library-system/`).

GitHub Pages only hosts static files and does not execute PHP or connect to MySQL. Deploy this application to a PHP-capable host to run it online.
